# 麻酔科医必要人数モニタリングダッシュボード

手術予定スケジュールに基づいて、麻酔科医の必要人数を15分単位で分析・可視化するダッシュボードです。

## 機能

- **エクセルファイルの読み込み**: 手術予定スケジュールをエクセルファイルから読み込み
- **15分単位の分析**: 手術スケジュールを15分単位で分析し、各時間帯の必要人数を計算
- **可視化**: グラフとテーブルで必要人数と配置人数を比較表示
- **余剰/不足の判定**: 各時間帯で麻酔科医が余っているか不足しているかを表示

## 使用方法

1. エクセルファイルを準備
   - 必須列: 入室時刻、手術開始予定時刻、手術終了予定時刻、退室予定時刻、手術内容
   - 時刻は `YYYY-MM-DD HH:MM` 形式または `MM-DD-YYYY HH:MM` 形式で入力

2. 麻酔科医の配置人数を入力
   - 研修医
   - 専攻医（非専門医）
   - 常勤専門医
   - 非常勤専門医

3. 「分析開始」ボタンをクリック

4. 結果を確認
   - 最大必要人数と現在の配置人数の比較
   - 15分単位のタイムライングラフ
   - 詳細データテーブル
   - 手術スケジュール一覧

## 必要人数の計算ロジック

手術内容と手術時間に基づいて必要人数を自動計算します：

- **心臓手術**: 2人
- **脳外科手術**: 2人
- **移植手術**: 3人
- **5時間以上の手術**: 2人
- **3時間以上の手術**: 1.5人（途中交代が必要）
- **その他**: 1人
